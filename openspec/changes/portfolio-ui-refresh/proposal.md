## Why

The current portfolio styling has drifted away from the earlier visual identity, especially the muted grey salutation and name treatment and the white hover effect that made the landing page feel more refined. At the same time, the supporting pages are using outdated or inconsistent copy, so the site needs a focused refresh that keeps the original aesthetic while updating the content across the portfolio.

## What Changes

- Restore the original grey text treatment for the salutation and name, with hover transitions to white to match the legacy look.
- Refresh the About and Projects page content so the portfolio reflects current experience, skills, and project work more accurately.
- Keep the dark theme and premium contrast while preserving the existing layout and navigation patterns.
- Standardize the page-to-page content and visual tone so the portfolio feels cohesive across home, About, and Projects views.

## Capabilities

### New Capabilities
- portfolio-ui-refresh: portfolio branding, text hierarchy, and supporting-page copy are refreshed while preserving the original grey-to-white interaction style.

### Modified Capabilities
- None

## Impact

- Static portfolio pages in the repository, including the home page and supporting content pages.
- Shared styling definitions in CSS and the small behavior layer in JavaScript.
- Project and personal biography copy only; no API or backend changes are required.
